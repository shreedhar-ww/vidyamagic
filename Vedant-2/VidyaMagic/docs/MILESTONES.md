# VidyaMagic — Product Milestones

> **Vision:** India's first themed adaptive learning PWA for Class 2 kids.
> Math + GK at launch. ₹99/year. Offline-first. Works on any device.

---

## Overview

| # | Milestone | Focus | Status |
|---|---|---|---|
| 1 | Foundation + Adaptive Math | PWA shell, theme system, Addition with adaptive engine, localStorage progress | 🔄 In Progress |
| 2 | Full Math Coverage | All 12 math topics with adaptive levels, section gating, progress map | ⬜ Planned |
| 3 | Bharat Discover (GK) | India map, 28 states, storytelling + quiz, cross-subject rewards | ⬜ Planned |
| 4 | Backend + Auth | Node + Postgres live, user accounts, progress sync, multi-device | ⬜ Planned |
| 5 | Payments + Subscription | Razorpay ₹99/year, free tier, family plan, school plan | ⬜ Planned |
| 6 | Parent Dashboard | Daily report, weak spots, screen time, WhatsApp summary | ⬜ Planned |
| 7 | AI Tutor | Claude API hints, personalized explanations, voice doubt | ⬜ Planned |
| 8 | Sounds + Polish | Background music, SFX, animations, eye-rest reminders | ⬜ Planned |
| 9 | Launch + Distribution | Domain live, school partnerships, WhatsApp referral, analytics | ⬜ Planned |
