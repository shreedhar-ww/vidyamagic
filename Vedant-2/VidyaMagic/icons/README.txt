PWA icons — REPLACE BEFORE LAUNCH

Required:
  icon-192.png  (192x192)
  icon-512.png  (512x512)

For dev, you can:
1. Generate at https://realfavicongenerator.net or https://maskable.app
2. Or use any 192/512 PNG with the VidyaMagic logo
3. Or use a tool: `npx pwa-asset-generator logo.svg ./icons`

Until icons exist, the PWA install prompt may not appear,
but everything else (offline, themes, adaptive engine) works.
